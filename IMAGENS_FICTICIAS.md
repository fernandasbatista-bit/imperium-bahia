# Imagens fictícias da IMPÉRIUM BAHIA

Foram criadas 52 ilustrações SVG próprias e locais, uma para cada produto. Os desenhos representam a **categoria e tipo do produto** pelo nome (tênis, camiseta, shorts, kimono, relógio etc.). **Não são fotos reais nem réplicas exatas dos modelos de marcas.** Cada ilustração recebe aviso visível de que é ilustrativa. Não foram copiadas imagens de Pinterest, lojas ou fabricantes.

Para operação comercial, substitua as ilustrações por fotos autorizadas, correspondentes ao SKU, cor e variante, antes de permitir a compra real. A foto enviada anteriormente pelo usuário para o item 3 foi mantida.
